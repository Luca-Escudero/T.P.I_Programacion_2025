# 🏆 CopaManager - Sistema de Gestión de Fútbol Amateur

## 📝 Descripción
**CopaManager** es una solución integral desarrollada en Java para la administración de campeonatos de fútbol 11 amateur. El sistema centraliza toda la logística de un torneo, desde la inscripción de participantes hasta la generación de estadísticas competitivas.

## 🚀 Funcionalidades Clave
* **Gestión de Planteles:** Registro completo de equipos y jugadores.
* **Fixture Inteligente:** Generación y visualización de los encuentros del torneo.
* **Estadísticas en Tiempo Real:** Carga de resultados con actualización automática de la **Tabla de Posiciones**.
* **Control Disciplinario:** Seguimiento detallado de jugadores sancionados y tarjetas.
