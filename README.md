# CopaManager

## Descripción

Sistema de gestión para campeonatos de fútbol 11 amateur. Administra equipos, jugadores, fixture, resultados, tablas de posiciones y sanciones.

## Funcionalidades Clave

* Registro de equipos y jugadores.
* Generación y visualización del fixture.
* Carga de resultados y estadísticas.
* Cálculo automático de la tabla de posiciones.
* Seguimiento de jugadores sancionados.

## Limitaciones

* Exclusivo para fútbol 11 amateur.
* No gestiona contratos, finanzas o fichajes.
